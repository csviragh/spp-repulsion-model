# SPP repulsion model

Continuous-time (ODE) self-propelled particle model in 2D, single-file browser simulator.

## Model
- dx_i/dt = v_i
- dv_i/dt = (v0 − |v_i|)/τ · v_i/|v_i| + Σ_j F0·S(r_ij)·e_ij  (e_ij: unit vector from j to i, minimum image)

## Repulsion sigmoid
S(r) = [σ((c−r)/w) − σ((c−R0)/w)] / [σ(c/w) − σ((c−R0)/w)], σ(z)=1/(1+e^−z), c = R0 − d/2, w = d/4.
S = 0 for r ≥ R0; d = 0 → Heaviside Θ(R0 − r). S(0)=1, S(R0)=0; d = R0 → nearly linear.

## Boundaries
- Torus: periodic in x and y.
- "Klein bottle" option: flipped periodic boundaries on both axes — crossing x maps y → L − y, vy → −vy; crossing y maps x → L − x, vx → −vx. Note: flipping both axes is topologically the real projective plane (RP²). Distances take the minimum over all images generated by up to two edge crossings (incl. corners).

- Möbius strip: crossing x maps y → L − y, vy → −vy; y is not periodic (hard reflecting walls at y = 0 and y = L).
- Sphere: flat square with glued edges — left edge to bottom ((0,t) ~ (t,0)), right edge to top ((L,t) ~ (t,L)). The gluing maps are ±90° rotations about the corners (0,0) and (L,L), which are cone points. This is a topological sphere, not a curved one.

All non-torus distances use images g(j) for g in the group generated by the gluing maps (compositions up to depth 2), taking the nearest; the force is rotated back into i's frame.

### Sphere 3D view
For the sphere option a rotatable 3D view (plain canvas, no dependencies) shows agents on S². Map: θ = π(x+y)/(2L) (cone points (0,0),(L,L) become the poles, the diagonal (0,L)–(L,0) the equator); on the line x+y=s, φ = 2πx/s for s ≤ L and φ = 2π(x−(s−L))/(2L−s) for s > L. Glued edge points map to the same point. Arrows are the pushed-forward velocity (finite-difference Jacobian).

## Numerics
Semi-implicit Euler, adjustable dt, cell list for O(N) neighbor search.

## Rendering
Agents drawn as uniform-colour balls (radius R0/2) with a velocity-direction arrow.

## Controls
N, R0, v0, d, L, τ, F0, dt, topology, start/pause/reset, speed. Live order parameter φ and mean speed.

## Run
Open `index.html` in a browser. Tests: `node test.js`.
